# Modèle institut de beauté — Maison Éclat

Elegant beauty spa / facialist website template in French: treatment menu, booking form, testimonials. Plain HTML/CSS/JS.

**Live demo:** https://abdelmoulabilel.github.io/beauty-spa-template/

![Preview](preview.webp)

## Use it
- Click **Use this template** on GitHub (or download the ZIP), then open `index.html` — no install, no build.
- Publish for free: repo **Settings → Pages → Deploy from branch → main / root**.

## Customise
Modifiez **`js/data.js`** : nom, e-mail, téléphone, adresse, position sur la carte, soins (par catégorie) et témoignages.
Pour recevoir les demandes par e-mail sans ouvrir la messagerie, collez une URL Formspree ou FormSubmit dans `formEndpoint`.
